About Pelliper

Pelliper is a fast, local-first Linux desktop email client built with Qt 6 / Kirigami and a background Rust sync daemon (pelliper-daemon).

  • Direct IMAP/SMTP sync with local SQLite caching for offline reading and fast search
  • OAuth 2.0 PKCE authentication for Gmail and standard IMAP/SMTP providers
  • Credentials stored locally in your desktop keyring (org.freedesktop.secrets)
  • Threaded conversations, attachments, rich HTML/plain-text viewing, and desktop notifications
